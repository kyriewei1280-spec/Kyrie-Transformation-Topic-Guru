# Kyrie Transformation Topic Guru

An interactive fieldbook synthesizing transformation-project experience from ten interview recordings.

## Explore

- Book-style table of contents with direct chapter navigation
- Seniority and speaker filters
- 63 challenge–action–lesson cases
- Searchable timestamped transcripts
- Responsive desktop and mobile layout
